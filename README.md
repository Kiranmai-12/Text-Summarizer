# Extractive Text Summarizer

Beginner-friendly Python/Streamlit project for learning and GitHub practice.

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Install packages:
   ```bash
   pip install -r requirements.txt
   ```
4. Start the app:
   ```bash
   streamlit run app.py
   ```
5. Open the local URL shown in the terminal, usually `http://localhost:8501`.

## Tech stack
Python, Streamlit, and the packages listed in `requirements.txt`.

## Note
This is an educational demo. Review and test results before relying on them in real-world situations.
